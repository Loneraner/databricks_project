# Databricks Project

This repository contains a structured learning path for Databricks with SQL and PySpark examples.

## Repository Structure

- **data/**: Sample CSV files for practice
- **sql/**: SQL scripts organized by day
- **pyspark/**: PySpark scripts organized by day
- **notebooks/**: Databricks notebooks for projects

## Days Overview

- **Day 1**: Delta Lake basics (schema, tables, CRUD, time travel, CDF)
- **Day 2**: SQL joins, aggregations, window functions, optimization
- **Day 3**: Streaming, Auto Loader, DLT
- **Day 4**: Unity Catalog, Delta Sharing, governance
- **Day 5**: Time series, SCD Type 2, CDC patterns
